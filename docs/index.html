LazyVM™

A PowerShell module that builds, looks after and disposes of Hyper-V virtual machines on a Windows host, unattended.

Alpha. LazyVM works, and its author uses it daily, but much of its behavior is still being worked on.

Today LazyVM makes development VMs: Windows 11 Enterprise Evaluation with Visual Studio, SQL Server Standard Developer and whatever other tools you install, with the 90-day evaluation handled for you. It uses every rearm Windows allows, then rebuilds the VM and puts your work back.

Download the latest release

What it does

Builds a VM with no input

Creates the VM, installs Windows from an answer file, then installs Visual Studio, SQL Server and your other tools.

Handles the 90-day evaluation

Rearms Windows while it can. When it can't, it captures your state, rebuilds the VM and puts everything back.

Keeps the VM up to date

Every night: Windows updates, winget upgrades, Store apps and Sysmon, restarting only when nobody is using the VM.

Checks security nightly

Defender scan, security baseline checks and persistence checks. It only reports, in plain words, with how to fix each finding.

Records what you change

Tools, settings, firewall rules, scheduled tasks and SQL logins are kept, so a rebuilt VM comes back as you left it.

Runs many VMs

Each VM has its own tools, disks, schedule and restore points. Source and files live on disks a rebuild never touches.

Requirements

  • Windows 10 or 11 Pro, Enterprise or Education on the host. Hyper-V is not available on Home.
  • PowerShell 7.6 or later, run as administrator.
  • A Windows account that is an administrator on the host.
  • A Windows 11 Enterprise Evaluation ISO from the Microsoft Evaluation Center.
  • Memory and disk for each VM: 8 GB of memory by default, growing to 16 GB, and dynamically expanding disks.

Install

Open PowerShell 7 (pwsh) as administrator, signed in as the user who will use LazyVM. Download LazyVM-<version>.zip from the latest release, then in the folder you saved it to:

Unblock-File .\LazyVM-*.zip
Expand-Archive .\LazyVM-*.zip -DestinationPath .\LazyVM -Force
.\LazyVM\Install.ps1

LazyVM is installed for one Windows user. Other standard users on the computer cannot use it or read what it stores.

Quick start

Build-LazyVM -Name DevBox

That is all. It takes an hour or two and needs no input. Running it again finishes an interrupted build. To sign in to the VM yourself, run:

Get-LazyVMCredential -Name DevBox -AsPlainText
