# Support

LazyVM is maintained by one person, so please use the channel that fits.

1. **Something is broken:** open a [bug report](https://github.com/downerboy/LazyVM/issues/new?template=bug_report.yml). Run `Test-LazyVM` first and include its output.
2. **It is hard to use with a screen reader or magnifier:** open an [accessibility issue](https://github.com/downerboy/LazyVM/issues/new?template=accessibility.yml). These are handled first.
3. **You want something new:** open a [feature request](https://github.com/downerboy/LazyVM/issues/new?template=feature_request.yml).
4. **You found a security problem:** do not open an issue. Follow [SECURITY.md](SECURITY.md).
5. **You want to learn how to use it:** read the [guide](docs/Guide.md) and the [use cases](docs/UseCases.md), and each command's help (`Get-Help <command> -Full`).

Only the latest release is supported.
